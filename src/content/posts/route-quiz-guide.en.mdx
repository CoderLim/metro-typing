Route quiz is the memory-first mode in Metro Typing. Instead of racing an entire typing run, you guess station names hidden on the map. It pairs well with typing practice when you know a line visually but freeze on the spelling.

## What you can adjust

The original game lets you tune difficulty, question count, region or route filters, and whether transfer stations appear. On easier levels, **initial-consonant (초성) hints** may help. Harder settings usually drop those hints so recall does more of the work.

## How to practice with quiz

1. Pick a line you already type somewhat well.
2. Start with hints on, then turn them off once answers feel cheap.
3. Note which transfer clusters you miss — those are the same places that stop the train in typing mode.
4. Switch back to a short typing run on that stretch the same day.

## Quiz vs single play

Quiz builds the mental map. Single play builds the finger path. Alternating both on one line is more efficient than only chasing finish times.

Full mode notes live in the [how-to-play guide](/how-to-play). When you are ready to type again, [open the homepage game](/#play).

## Start with a five-station neighborhood

Choose an anchor such as Sadang on Line 2 or Gongdeok on Line 6, then set a small group around it. Answer the stations forward first, then try to name them in reverse. Reverse recall exposes whether you know a map shape or only a familiar travel direction, and it makes a later typing run less dependent on guessing.

## Turn misses into typing drills

When a quiz answer is wrong, note the station before it and the expected station. For example, if you miss the station after Jamsil, type the small Jamsil–Seokchon–Songpa cluster three times in typing mode. Do not immediately retry a large quiz set: pairing one missed answer with a short input drill creates a clearer correction loop.

## Measure recall separately from spelling

Give yourself two marks after a quiz: “did not know the next station” and “knew it but could not spell it quickly.” A high recall score with slow input points toward Hangul rhythm practice; low recall with clean spelling points toward route-memory practice. This distinction keeps quiz mode from becoming another vague score chase.

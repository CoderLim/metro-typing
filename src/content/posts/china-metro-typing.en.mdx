If you already play Seoul station-name typing here, China Metro Typing is the mainland counterpart: real lines, real order, and a train that only moves when you type the next stop correctly. The open-source game lives at [metro-typing.fun](https://metro-typing.fun) and the code is on [GitHub (Evenss/metro-typing)](https://github.com/Evenss/metro-typing).

## What China Metro Typing is

China Metro Typing turns a city’s subway map into a typing drill. You pick a line, a segment, and a direction, then type each station name in order. Correct characters push the train forward; mistakes hold you in place. Speed, accuracy, and progress stay on screen while you run.

It is not a random-word typing test. The challenge is recalling the next stop and spelling it under a clock — the same loop as [how we play Metro Typing](/how-to-play), applied to Chinese networks.

## How to play on metro-typing.fun

1. Choose a line from the map or the line list.
2. Set the segment, direction, and name style: English or pinyin.
3. Pick a mode:
   - **30 Seconds** — type as far as you can before time runs out (or finish early if you clear the stretch).
   - **Full Line** — follow the real station order end to end.
4. Start the line and type the name shown. Spaces in English and pinyin are optional. In pinyin mode use a Latin keyboard, skip tones, and type `ü` as `v`.
5. Watch speed, accuracy, and progress update as each correct character advances the train.

No install is required — open [metro-typing.fun](https://metro-typing.fun) and play in the browser.

## English names vs pinyin

English romanization helps if you read tourist maps or compare spellings across apps. Pinyin is closer to how many riders search and type Chinese names on a Latin keyboard. Keep one style for a whole session so your fingers learn one map, not two.

That advice mirrors [Hangul vs English station input](/blog/hangul-vs-english-input) on this site: mixing scripts mid-run usually costs more time than a slower, consistent run.

## Open source, MIT code, data caveats

The game is MIT-licensed source on [Evenss/metro-typing](https://github.com/Evenss/metro-typing). You can star the repo, run it locally with Node.js 22.13+, and inspect how lines are loaded.

Metro route and station data are **not** covered by that MIT grant — usage still follows each data source’s terms. The maintainers call this out in the README; treat maps and station lists as third-party data, not free-to-republish assets.

The concept builds on [TAIWAN METRO TYPING](https://tw-metro-typing.yencheng.dev/), the same inspiration thread behind many station-typing games. China Metro Typing extends that idea across multiple mainland cities.
